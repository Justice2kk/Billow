# Public platform roadmap

Priorities are tied to implementation gates rather than dates:

1. certify the standards-language Creator path end to end (TypeScript/JavaScript/Luau);
2. finish production HTML/CSS Browser/Sites cutover without weakening publication/security authority;
3. promote page-program JS/TS APIs from experimental only after integrated runtime acceptance;
4. expand compatibility entries alongside conformance/regression tests;
5. publish a stable standards-based site/project packaging contract when its production owner is certified;
6. grow examples into installable/publishable projects only when those contracts are real.

This is not a promise that every browser feature will be implemented. Some features are intentionally outside Billow's model.
