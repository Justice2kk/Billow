# Basic HTML/CSS source example

`index.html` and `styles.css` stay inside the currently documented Billow HTML/CSS profile and are useful as conformance/learning source.

This example intentionally does **not** include a site packaging/publishing manifest. The production standards-based site packaging path is still being cut over, and this repository will not invent a manifest format before that contract is certified.

Use the [compatibility index](../../../docs/compatibility/FEATURES.md) for exact support claims.
