# Billow compatibility index

> Generated from `compatibility/registry.json`. Do not edit this file by hand.

This index answers: **external concept → Billow equivalent → current support level**. A status applies only to the named feature; it is not a claim that Billow is a full browser/standards implementation.

## Status meanings

- **`supported`** — Available in the documented public profile without a material Billow-specific limitation for the named concept.
- **`supported_with_limits`** — Available, but Billow intentionally supports a bounded subset or documented divergence.
- **`experimental`** — Implemented or under active integration; public shape/availability may change before certification.
- **`unsupported`** — Not available in the current profile; future support is not committed.
- **`intentionally_unsupported`** — Deliberately excluded from the Billow public model/security boundary.
- **`billow_extension`** — Billow-native capability with no standards-equivalence claim.
- **`deprecated`** — Legacy/superseded vocabulary retained for migration/history.
- **`planned`** — Intended direction without a current implementation claim.
