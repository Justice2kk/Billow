# Glossary

**Capability** — explicit authority granted by Billow to perform a bounded operation. A manifest/API request is not itself a grant.

**Handle** — opaque, context-bound reference to a resource such as a file or window.

**Origin** — security identity for a Billow web document/site. Origin-scoped state is isolated.

**Deployment** — immutable built/published website revision selected by a route.

**Route** — logical mapping from a `billow://` authority/path space to approved immutable deployment state.

**Page program** — sandboxed behavior for a web document; lower trust than the Browser shell.

**Billow-native / extension** — capability designed for Billow without claiming standards equivalence.

**Supported with limits** — familiar knowledge transfers, but only the documented subset is promised.

**Experimental** — implementation exists or is being integrated; the public contract may change before certification.
